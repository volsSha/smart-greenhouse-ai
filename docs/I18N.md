# Internationalization

The UI supports English and Ukrainian with Python `gettext` catalogs. User language preference is stored in NiceGUI user storage and selected from the header switcher.

## Adding translatable UI text

Import the translation helper in NiceGUI UI modules:

```python
from app.i18n.core import _
```

Wrap user-facing labels, buttons, placeholders, tooltips, notifications, and empty/error state messages:

```python
ui.label(_("Dashboard"))
ui.notify(_("Failed to load commands: {error}", error=detail), type="negative")
```

Use named placeholders instead of f-strings inside translatable strings. This keeps the source text extractable and lets translators reorder values if needed.

Do not translate user-generated content, database values, backend API response bodies, model output, IDs, or internal logs.

## Dynamic labels

Babel only extracts literal strings. Avoid passing dictionary values or computed strings to `_()`:

```python
# Avoid
_(config["label"])

# Prefer
def status_label(status: str) -> str:
    labels = {
        "ok": _("Success"),
        "error": _("Error"),
    }
    return labels.get(status, labels["ok"])
```

## Updating catalogs

After adding or changing UI text, regenerate and compile catalogs:

```bash
uv run pybabel extract -F babel.cfg -o locales/messages.pot .
uv run pybabel update -i locales/messages.pot -d locales
uv run pybabel compile -d locales
```

Fill `msgstr` values in both catalogs before compiling:

- `locales/en/LC_MESSAGES/messages.po`
- `locales/uk/LC_MESSAGES/messages.po`

English entries should mirror the source text unless wording needs to differ. Ukrainian entries should contain the translated UI text.

Compiled `.mo` files are generated artifacts and are ignored by git.

## Tests

Run focused i18n checks after changing the translation core or language switcher:

```bash
uv run pytest tests/unit/test_i18n_core.py tests/unit/test_language_switcher.py
```

Run Python compilation for broad UI syntax validation:

```bash
uv run python -m compileall app/i18n app/ui
```
